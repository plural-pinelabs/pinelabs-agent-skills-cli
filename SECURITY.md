# Security Policy

## Reporting a Vulnerability

Please report security issues affecting `pinelabs-agent-skills-cli` or any other Pine Labs developer package to **security@pinelabs.com**. Do not open a public GitHub issue.

We will acknowledge receipt within 2 business days and aim to provide a remediation timeline within 5 business days.

## Supported Versions

| Version | Supported |
| --- | --- |
| >= 0.1.x | Yes |

## Disclosure Process

1. Report received and acknowledged.
2. Triage and fix on a private branch.
3. Coordinated release with credit if requested.
4. Public advisory through GitHub Security Advisories and npm registry metadata.
